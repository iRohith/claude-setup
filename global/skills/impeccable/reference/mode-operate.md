# Operate

Rules for the directions in [new-work-world.md](new-work-world.md) and for the build. The visitor came to get a job done: the page is first a working product of its category, and the world serves it.

## Directions
- A user of such tools knows where everything is before noticing the world. The world lends only type, palette, density and one signature move; never the layout, navigation model or controls.
- Colour does real jobs: a committed shell palette (coloured rail or header, tinted ground), state colours, data series, selection, the signature move. A grey screen with one accent is the default, not restraint.
- A world taken from a tool the audience operates (terminal, scope, control panel, cockpit), a fictional interface or any interface language gives only those four things, or is replaced from your list.
- Write each first viewport shell first: navigation, work areas and their jobs, the data read first and its states, then where the signature move lives, named concretely (service health as a transit map, a schedule in timetable rhythm). A world that shows only as a colour scheme has no move yet. Product clarity includes reading as a working product of the category.

## Build
- The product screen in the committed palette: shell and navigation, a distinct area per job, filters over what they scope, charts and tables with clear states. It never reads as a newspaper, poster or other world artifact.
- Standard controls only (shadcn on the web, native controls in an app): buttons, tabs, inputs, selects, sortable tables, navigation that reads as navigation. Never a costume: function-key bars, command prompts, instrument bezels, ledger paper for tables.
- The bar is the category's best product: aligned grid, consistent spacing, real type scale, clear hierarchy. The signature move adds to that, never replaces it.
- Real content: product name, plausible data with units, real labels, and one state worth seeing (an alert, a degraded service, an empty result). State colours only where they carry meaning; a headline number that moves shows its recent history and marks when it changed.
- Self-check: with the name covered, does it read as a product of its category, can the task be done, is it at least as clean as the standard and more distinctive? If it reads as a world artifact first, rebuild with the shell named region by region.
