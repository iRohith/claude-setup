# Read

Rules for the directions in [new-work-world.md](new-work-world.md) and for the build. The visitor came to understand something: the page is first a document of its kind, framed by the world.

## Directions
- The reader's question leads; comprehension and wayfinding stay intact. Docs read as docs, a guide as a guide, an article as an article.
- The world owns the frame (masthead, navigation rail, ground, title and section openers, how code, tables and callouts are set) and commits fully there; the reading column stays calm. It never sets the reading order or swaps navigation for something to learn.
- The world's publishing traditions transfer best: reference books, type specimens, timetables, field guides, manuals, scholarly apparatus, newspaper wayfinding. A tool, instrument, fictional interface or interface language lends only type, palette, density and one signature move; navigation and controls stay standard.
- Write each first viewport shell first: navigation and where the reader stands, the title and an opening that answers the question, the column, the way forward (contents, headings, next and previous). Then where the world owns the frame and the signature move (running head, margin system, numbering, code setting). Product clarity includes how fast a reader finds the answer.

## Build
- A world-owned frame around a calm column: about 60–75 characters with body near 16px on the web (native: the platform body style and readable width), clear heading hierarchy, wayfinding throughout.
- Body in a reading face with real contrast; monospace only for code, parameters and small labels.
- Code, tables, notes and figures in their standard forms, in the world's type and palette. The signature move is one system where it earns its place, not a frame around everything.
- Real material: the actual title, a real opening, real section names, and the hardest content the surface holds (a code sample, reference table or diagram).
- Self-check: can a reader tell where they are and where to go next, and read comfortably? With the name covered, could it be any product's docs? Then push the frame further into the world. If it reads as a world artifact before a document, pull the world out of the column.
